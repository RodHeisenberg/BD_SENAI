# Aula 01 - Banco de Dados

## Fundamentos de Banco de Dados e Levantamento de Requisitos

Este repositório contém uma atividade interativa da primeira aula da Unidade Curricular de Banco de Dados.

O objetivo é praticar os conceitos iniciais antes de avançarmos para modelagem de dados, DER e SQL.

## O que você vai praticar

Durante a atividade, você irá:

- diferenciar dado e informação;
- identificar usuários de um sistema;
- reconhecer processos;
- identificar dados que precisam ser armazenados;
- reconhecer regras de negócio;
- identificar possíveis entidades;
- organizar uma matriz simples de requisitos.

## Cenário

A atividade utiliza como cenário a Clínica Bem-Estar.

A clínica registra informações de pacientes, profissionais, consultas e procedimentos. Parte desses dados está distribuída em fichas e planilhas.

Nosso objetivo é entender o problema antes de criar tabelas ou escrever comandos SQL.

## Como realizar a atividade

1. Acesse o link disponibilizado pelo professor.
2. Comece pela etapa Dado ou Informação.
3. Responda às questões antes de conferir o resultado.
4. Na etapa da Clínica Bem-Estar, classifique os itens apresentados.
5. Monte a matriz de requisitos.
6. Realize o desafio final sobre teleconsulta.
7. Anote suas dúvidas para discutirmos em aula.

## Importante

Nesta aula, não estamos criando o banco de dados ainda.

Antes de construir tabelas, precisamos responder perguntas como:

- Quem utiliza o sistema?
- O que cada usuário precisa fazer?
- Quais dados precisam ser armazenados?
- Quais regras o sistema precisa respeitar?
- Quais elementos podem se tornar entidades do banco?

## Desafio final

A Clínica Bem-Estar começou a oferecer teleconsultas.

Analise a mudança e identifique:

- usuários envolvidos;
- novos dados necessários;
- regras de negócio;
- possíveis alterações nas entidades.

Não existe apenas uma resposta possível. O importante é justificar suas escolhas de acordo com o cenário.
